# Student Marks Calculator

This is a simple Python program created for Applications of ICT Assignment 1.

## What the program does

- Asks for the student's name.
- Takes ICT, DLD and DSA marks out of 100.
- Checks whether the marks are between 0 and 100.
- Calculates the total and percentage.
- Displays a grade.

## Requirements

Python 3. No extra libraries are required.

## How to run

Open a terminal in the project folder and enter:

    python marks_calculator.py

On Windows, you can also try:

    py marks_calculator.py

Enter a name and numeric marks when prompted.

## Example

ICT: 80
DLD: 70
DSA: 90

Total: 240 out of 300
Percentage: 80%
Grade: A

## Example grading rules

- A: 80% and above
- B: 70% to below 80%
- C: 60% to below 70%
- D: 50% to below 60%
- F: Below 50%

These are example grading rules for this program.

## Limitation

The program expects numeric input for marks.
